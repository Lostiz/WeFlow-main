## 新增 GitHub Actions 工作流（WeFlow）

分析项目后新增两个工作流文件，未改动已有 release.yml / wcdb-compatibility.yml：

- `.github/workflows/ci.yml`：push/PR 到 main|master|dev + 手动触发。
  - job `quality`（ubuntu-latest + windows-latest 矩阵）：`npm ci --ignore-scripts --legacy-peer-deps --no-audit --no-fund` → `typecheck:renderer` → `typecheck:electron` → `test:wcdb`
  - job `build`（同矩阵，needs: quality）：`node scripts/clean-dist-electron.cjs` → `npx vite build` → 校验 dist/index.html 与 dist-electron/{main,preload}.js → ubuntu 上传产物
- `.github/workflows/package.yml`：workflow_dispatch + push 到 main|master。三平台 electron-builder 打包校验（--publish never + --config.npmRebuild=false），产物仅上传 Artifacts；macOS 保留 DMG 失败降级为 ZIP 的逻辑。

## 项目关键事实（后续续用时直接引用）

- 类型：Electron 桌面应用（Vite 8 + React 19 + TS 6）；渲染层 `src/`，主进程/预加载/10 个 Worker 在 `electron/`；打包用 electron-builder，产物到 `release/`。
- 包管理器：npm（仅提交 package-lock.json；pnpm-lock.yaml 在 .gitignore 中，勿改用 pnpm）。
- Node 版本约定 24（既有 workflow、`check-wcdb-optional-exports.cjs` 的 esbuild target 均为 node24）。
- **无 ESLint/Prettier 配置**：静态检查只能靠 `typecheck:renderer` / `typecheck:electron`（tsc），不存在 lint 脚本。
- CI 安装依赖必须带 `--ignore-scripts`：postinstall 里的 patch-package、electron-builder install-app-deps、prepare-electron-runtime.cjs 都需要本机工具链，且 `patches/` 目录被 gitignore。
- 原生依赖（koffi / sherpa-onnx-node / silk-wasm / sharp）在 CI 中不重建；打包步骤需显式 `--config.npmRebuild=false`。
- 第三方可插拔组件（WCDB 动态库、媒体解密 .node 插件、WeLive 可执行文件）由用户运行时提供，检查与构建均不需要。
- 分支情况：git 实测远端只有 `main`（dependabot 里写的 `dev` 并不存在），工作流按 main|master|dev 触发以兼容，需收紧时改 `[main]`。

## 修复 CI 构建失败：Rolldown failed to resolve import @lobehub/ui（已端到端验证）

**根因**：`@lobehub/ui` 与 `antd` 在 package.json 里**不是直接依赖**，只是 `@lobehub/icons` 的 peerDependency（package-lock.json 中该节点带 `"peer": true`）。`@lobehub/icons/es/features/ProviderIcon/DefaultAvatar.js` 会 `import '@lobehub/ui'`。

关键差异：**npm 10 与 npm 11 对 `--legacy-peer-deps` 的处理不同**（实测 npm 11.21.0 vs 10.9.7，同一 lockfile）：

| 命令 | npm 10 结果 | npm 11 结果 |
|---|---|---|
| `npm ci --legacy-peer-deps` | 1398 包，含 @lobehub/ui | **1038 包，无 @lobehub/ui → 构建失败** |
| `npm ci`（无开关） | ERESOLVE 失败 | ERESOLVE 失败（ansi-to-react 的 peer 与 react 19 冲突） |
| `npm ci --force` | — | **1271 包，含 @lobehub/ui + antd ✅** |

GitHub 的 Node 24 自带 npm 11，所以本地 npm 10 装出来的树是好的、CI 却缺 peer —— 这就是"本地能过、CI 报错"的原因。

**修复**：`NPM_CI_FLAGS` 从 `--ignore-scripts --legacy-peer-deps --no-audit --no-fund` 改为 `--ignore-scripts --force --no-audit --no-fund`；另加一个"Ensure build-time peer dependencies"步骤按 package-lock.json 版本兜底补装 @lobehub/ui / antd，仍缺失则 `::error::` 明确失败。

**验证（本地用 npm 11.21 + Node 22 实跑）**：`npm ci --ignore-scripts --force` 装出 1271 包且 @lobehub/ui 5.20.0 / antd 6.5.0 存在 → `vite build` 成功，产出 dist/index.html + dist-electron/{main,preload,...}.js；`typecheck:renderer`/`typecheck:electron` 退出码 0；`test:wcdb` 42/42 通过。验证后已删除 node_modules / dist / dist-electron / tmp / tsconfig.node.tsbuildinfo。

**后续可选（需改 package.json + 重生成锁文件，本轮未做）**：把 `@lobehub/ui`、`antd` 提升为直接 dependencies，即可彻底摆脱对 peer 自动安装的依赖。
